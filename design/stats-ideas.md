# Stats ideas

Each idea becomes one stat plugin (`docs/js/domain/stats/catalog/<id>.js`) — see spec §9.
Mark ideas `[x]` when shipped.

## Starter set (phase 3)
- [ ] Elo leaderboard with change in selected season
- [ ] Season summary: nights, matches, games, draw %
- [ ] Record: longest match (games)
- [ ] Record: longest draw streak
- [ ] Record: clean sweeps (3–0 without draws)
- [ ] Record: comebacks (0–2 → 3–2)
- [ ] Record: biggest upset
- [ ] Player: Elo over time
- [ ] Player: games W/D/L, win %; matches W/L, win %; draw rate
- [ ] Player: streaks (win / unbeaten / loss; current and longest)
- [ ] Player: partners and opponents tables; best partner; nemesis
- [ ] Pairs table; pair W/D/L, win %, head-to-head vs other pairs
- [ ] Compare: player stats side by side, Elo overlay, record together / against

## Ideas
- Night winners (largest Elo gain per night)
- Form (last 10 games)
- Nights attended, attendance rate
- Sit-outs per player
- Favourite victim (opponent beaten most)
- Most draws in a match
- Highest Elo ever / lowest Elo ever
- Longest win streak (overall record)
- Worst partner
- Average games per match; draw rate trend over time
